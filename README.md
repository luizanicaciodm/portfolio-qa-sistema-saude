# 🏥 Portfólio QA — Sistema de Saúde
> Plano de Saúde | Laboratório Clínico | Análises Clínicas

## 📌 Sobre o Projeto

Portfólio completo de **Quality Assurance (QA)** baseado na simulação de um
sistema real da área da saúde. O projeto abrange operações de plano de saúde,
exclusão de beneficiários via API, fluxos de pacientes e validação de regras
clínicas críticas.

> 💡 **Diferencial:** Este portfólio incorpora conhecimento prático em
> **análises clínicas e garantia da qualidade laboratorial**, trazendo
> regras de negócio que vão além da validação técnica.

## 🎯 Objetivos

- Demonstrar habilidades em testes funcionais, API, banco de dados e automação
- Simular um ambiente corporativo real da área da saúde
- Aplicar conceitos de qualidade com foco em domínio clínico
- Evidenciar pensamento estratégico e tomada de decisão em QA

## 🗂️ Estrutura do Projeto

```
portfolio-qa-sistema-saude/
│
├── 01-planejamento-de-testes/     # Plano de teste, casos de teste
├── 02-gestao-de-defeitos/         # Bug reports detalhados
├── 03-validacoes-em-banco-de-dados/ # Queries SQL de validação
├── 04-testes-de-api/
│   └── api-exclusao-beneficiarios/  # Coleção Postman + documentação
├── 05-automacao-de-testes/
│   └── fluxo-do-paciente/           # Scripts Cypress E2E
├── 06-checklists-de-qualidade/    # Checklists de regressão
├── 07-testes-de-performance/      # Plano + script k6
├── 08-testes-de-seguranca/        # Cenários e payloads
└── 09-casos-de-negocio-em-saude/  # Regras clínicas críticas
```

## 🛠️ Ferramentas

| Ferramenta | Finalidade |
|---|---|
| Postman | Testes de API |
| Cypress | Automação E2E |
| SQL | Validações de banco |
| Git / GitHub | Controle de versão |
| k6 | Testes de performance |

## 🔬 Contexto Clínico

Este projeto aplica regras reais de laboratório clínico:
- Validação de resultados críticos (glicose, hemoglobina, plaquetas)
- Inconsistência entre sexo e tipo de exame
- Alertas médicos obrigatórios por valor fora da faixa de referência
- Regras regulatórias de exclusão de beneficiários
